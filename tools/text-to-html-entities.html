What are HTML Entities?

HTML entities are special codes that represent reserved characters in HTML. For example, < represents <, > represents >, and & represents &. Encoding text to entities prevents browsers from interpreting code as HTML, ensuring safe display of user-generated content and code snippets.

Frequently Asked Questions

Why encode HTML entities?
To prevent XSS attacks and ensure text displays exactly as written. When you show user comments or code examples, encoding stops browsers from executing embedded scripts or tags.
What's the difference between & and &?
& is the HTML entity for the ampersand character itself. If you write & directly in HTML, it might be interpreted as the start of another entity.
Should I encode quotes?
Yes, especially when placing text inside HTML attributes. " represents double quotes and ' represents single quotes to prevent breaking the attribute syntax.
