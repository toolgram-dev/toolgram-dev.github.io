Unix File Permissions

CHMOD (Change Mode) sets file permissions using octal numbers. Each digit represents owner, group, and public permissions. Values are calculated by adding: Read(4) + Write(2) + Execute(1).

Frequently Asked Questions

What does 755 mean?

Owner can read, write, execute (4+2+1=7). Group can read, execute (4+1=5). Public can read, execute (4+1=5). Common for web directories.

Why 644 for files?

Owner read/write (4+2=6). Group read (4). Public read (4). Secure for regular files.
