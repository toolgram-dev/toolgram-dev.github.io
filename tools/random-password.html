What Makes a Password Secure?

Password security depends on entropy—unpredictability measured in bits. Length and character variety increase entropy. Our generator uses crypto.getRandomValues() for true randomness, avoiding predictable Math.random(). Each password is unique and resistant to brute-force attacks.

Frequently Asked Questions

Why not use Math.random()?
Math.random() is not cryptographically secure—it's predictable. Our generator uses crypto.getRandomValues() which provides true random numbers suitable for passwords and security tokens.
What password length is recommended?
12-16 characters is minimum for most uses. For high security (master passwords), use 20+ characters with all character types enabled.
Should I exclude ambiguous characters?
Yes for human-readable passwords. Characters like 0,O,I,l can be confusing. Our option removes them for easier typing.
