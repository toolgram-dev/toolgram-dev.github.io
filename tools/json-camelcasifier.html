snake_case vs camelCase

Databases often use snake_case (user_id), while JavaScript/TypeScript prefer camelCase (userId). Our tool recursively converts all JSON keys to camelCase, making API responses frontend-ready.

Frequently Asked Questions

What's the conversion rule?

snake_case: user_profile → camelCase: userProfile. Underscores removed, next letter capitalized. First letter lowercase.

Does it handle nested objects?

Yes, recursively processes all nested objects and arrays, converting every key at every level.
