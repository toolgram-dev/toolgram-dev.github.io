What is Punycode?

Punycode is a way to represent international characters (Unicode) in domain names using only ASCII characters. It starts with "xn--" followed by encoded characters. This allows non-English domains like "münchen.de" to work in DNS systems that only understand ASCII.

Frequently Asked Questions

Why do we need Punycode?
The DNS system was originally designed for ASCII only. Punycode bridges the gap, allowing international domain names (IDNs) to work everywhere while displaying as native characters in browsers.
What does xn-- mean?
The "xn--" prefix indicates that the domain uses Punycode encoding. It tells browsers and DNS servers to decode the rest as an international domain name.
Are Punycode domains safe?
Yes, but beware of homograph attacks where similar-looking characters (like Cyrillic 'а' vs Latin 'a') create fake domains. Modern browsers show Punycode for mixed-script domains to prevent this.
