What is a Web App Manifest?

The web app manifest is a JSON file that tells browsers about your Progressive Web App (PWA). It controls how your app appears when installed on a user's device, including name, icons, theme colors, and display mode. Essential for making any website installable like a native app.

Frequently Asked Questions

What icons do I need for PWA?
At minimum, include 192x192 and 512x512 icons. Different devices use different sizes. Our generator includes placeholder icons—replace with your actual icon paths.
Where do I put the manifest file?
Save as manifest.json in your root directory and link it in HTML: <link rel="manifest" href="/manifest.json">. Also include a service worker for full PWA functionality.
What's the difference between standalone and fullscreen?
Standalone hides browser UI but shows system status bar. Fullscreen hides everything for immersive experiences like games. Minimal-ui shows some navigation controls.
