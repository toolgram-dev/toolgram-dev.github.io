What is Morse Code?

Morse code represents letters and numbers using sequences of dots (.) and dashes (-). Invented for telegraphy, it's still used in aviation, amateur radio, and emergency signaling. Each character has a unique pattern: A = .-, B = -..., SOS = ... --- ... (the universal distress signal).

Frequently Asked Questions

How do I read Morse code timing?
Dot = 1 unit, dash = 3 units, space between parts of same letter = 1 unit, between letters = 3 units, between words = 7 units. Our translator uses standard spacing.
What's the fastest way to learn Morse?
Learn by sound (not visual patterns). Start with 5-10 letters at 20 WPM with wide spacing, then gradually increase speed. Apps like Morse Toad and LCWO.net help.
Is Morse code still used?
Yes! In amateur radio (CW mode), aviation (NDB identifiers), and as an assistive technology. The US Navy still trains some personnel in Morse for emergency communications.
