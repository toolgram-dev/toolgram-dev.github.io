What are Markdown Tables?

Markdown tables use pipes (|) and hyphens (-) to create formatted tables. The first row is headers, second row defines alignment (|:---| left, |:---:| center, |---:| right). Each cell is separated by pipes. Popular on GitHub, GitLab, and in README files for clean documentation.

Frequently Asked Questions

How do I align text in markdown tables?
Use colons in the separator row: :--- for left, :---: for center, ---: for right. The hyphens count doesn't matter, but at least three are recommended.
Can I have line breaks in cells?
Yes! Use
HTML tag inside cells for line breaks. Markdown itself doesn't support multi-line cells, but HTML works within markdown tables.
Why isn't my table rendering on GitHub?
Ensure header row, separator row, and data rows all have the same number of pipes. Missing pipes or inconsistent columns break the table. Our generator ensures valid syntax.
