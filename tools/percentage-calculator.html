How to Use Percentage Calculator

Three calculation modes: "X% of Y" calculates the percentage of a number. "Percentage change" calculates the increase/decrease between two values. "X is what % of Y" finds what percentage one number is of another. All results are shown instantly.

Frequently Asked Questions

How do I calculate percentage increase?
Use the "Percentage change" mode. Enter the original value as "From" and the new value as "To". The result shows the percentage increase or decrease.
How accurate are the calculations?
All calculations are performed with standard JavaScript arithmetic and rounded to two decimal places for display.
Can I use decimal numbers?
Yes, you can enter decimal values in any input field for precise calculations.
