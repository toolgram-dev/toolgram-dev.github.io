What is Gzip?

Gzip is a compression format based on the DEFLATE algorithm. It's widely used for file compression, web content encoding (HTTP compression), and data transfer. Our decompressor extracts original content from gzipped data, supporting base64-encoded input for easy pasting.

Frequently Asked Questions

What's the difference between gzip and zip?
Gzip compresses single files; zip archives multiple files. Gzip is often used with tar for directories (tar.gz). Both use DEFLATE but with different headers.
How do I decompress gzip from a file?
Use the "Upload File" button to select a .gz file. Our tool reads it as binary, decompresses it, and shows the content. Files under 10MB work best.
Why do I see base64 strings?
Base64 encoding is common for embedding binary data in text (JSON, XML, APIs). Our tool auto-detects and decodes base64 before decompression.
