What is JSONPath?

JSONPath is a query language for JSON, similar to XPath for XML. It lets you extract specific data from complex JSON structures. Use dot notation ($.store.book[0].title) or bracket notation ($['store']['book'][0]['title']) to navigate and filter JSON data efficiently.

Frequently Asked Questions

What's the difference between $.* and $..*?
$.* selects immediate children, while $..* is recursive descent (searches all levels). Use .. when you don't know the exact path or want all matching properties anywhere.
How do I filter by value?
Use [?()] syntax: $.users[?(@.age>25)]. This filters array items where age > 25. Supports comparisons, logical operators, and regular expressions.
What's JSON Pointer vs JSONPath?
JSON Pointer (RFC 6901) is simpler, using /-separated paths like /users/0/name. JSONPath is more powerful with filtering and wildcards but not an official standard.
