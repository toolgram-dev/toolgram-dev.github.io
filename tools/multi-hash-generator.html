What is a Cryptographic Hash?

A cryptographic hash function takes an input (or 'message') and returns a fixed-size string of bytes. The output, or hash, is unique to each input. Even a tiny change in the input produces a completely different hash. This tool generates multiple hashes at once for easy comparison.

Frequently Asked Questions

What is the difference between MD5 and SHA256?
MD5 produces a 128-bit hash and is considered cryptographically broken for security purposes. SHA256 produces a 256-bit hash and is currently secure for most applications.
Can I decrypt a hash?
No, hashing is a one-way function. You cannot 'decrypt' a hash back to its original text.
