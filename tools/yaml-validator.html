What is YAML?

YAML (YAML Ain't Markup Language) is a human-readable data serialization standard used for configuration files, data exchange, and application settings. It relies on indentation for structure, making proper syntax critical. Our validator checks for indentation errors, duplicate keys, and valid YAML syntax.

Frequently Asked Questions

Why is indentation important?
YAML uses spaces (not tabs) for structure. Incorrect indentation is the most common error. Each level must use consistent spacing—typically 2 spaces per level.
What's the difference between YAML and JSON?
YAML is more human-readable with less syntax (no brackets/commas). It supports comments, multiple document streams, and complex data types. JSON is machine-friendly and stricter.
Can YAML contain multiple documents?
Yes! Use `---` to separate documents and `...` to end a document. Our validator checks each document individually in multi-document files.
