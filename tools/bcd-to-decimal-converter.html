What is Binary Coded Decimal?

BCD (Binary Coded Decimal) represents each decimal digit with its own 4-bit binary value. For example, decimal 975 becomes 1001 (9), 0111 (7), 0101 (5). This format is common in digital displays, real-time clocks, and legacy industrial equipment where decimal precision matters.

Frequently Asked Questions

Why use BCD instead of binary?
BCD avoids binary-to-decimal conversion errors in financial systems, digital scales, and displays. Each digit is independently encoded, making it easier to drive 7-segment displays and maintain decimal accuracy.
What's the difference between packed and unpacked?
Packed BCD stores two digits per byte (e.g., 0x97 for 97). Unpacked BCD uses one digit per byte (e.g., 0x09, 0x07). Our converter handles both formats.
What happens if a nibble is >9?
Valid BCD only uses 0000-1001 (0-9). Values 1010-1111 (10-15) are invalid. Our validator alerts you to invalid BCD digits.
